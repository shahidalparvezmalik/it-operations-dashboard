# IT Operations Dashboard

[![Python validation](https://github.com/shahidalparvezmalik/it-operations-dashboard/actions/workflows/python.yml/badge.svg)](https://github.com/shahidalparvezmalik/it-operations-dashboard/actions/workflows/python.yml)

A portfolio proof of concept using 1,200 synthetic ITSM incident records to demonstrate management KPIs, operational reporting, and a Power BI implementation guide.
